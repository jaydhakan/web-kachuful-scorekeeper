# Inspiration log

What was researched, what could actually be verified, and where each idea landed. Facts are only listed as facts when the page could be read. Awwwards blocks most of its own pages from automated readers, so for several sites only names were available.

## Verified and used

| Source | What was verified | Where it landed |
|---|---|---|
| Thick Pickle (Awwwards Site of the Day) | One accent colour, `#8EFF00` acid lime | Exploration 16 Lime Brutal (not in the final three) |
| Mana Yerba Mate (Awwwards Site of the Day) | Palette `#FFD372` and `#F15B40`; Animations/Transitions score 9.2/10; tagged pastel colours, CSS animations, WebGL, loading animations; has a jump mini-game | Theme **Yerba Sun** (final version uses a softer butter background and a tomato accent); squash-and-stretch loader |
| Dropbox Brand site (Awwwards Site of the Month, Feb 2025) | Style reference tokens: `#101010`, `#E5EDE4`, `#C7D8C5`, `#B8AFDA`, `#EB652B`, `#F6F361`; display serif plus a clean sans; pill shapes; no box-shadows, contrast does the separation. Built with Rive state machines | Exploration 22 Obsidian Ember; bid pop |
| Corn Revolution by Resn (Awwwards Site of the Month, Jul 2020) | Scroll-driven 3D story, headline with an animated outline, a plant leaf that follows the mouse; built on three.js and GSAP | Outline-to-fill headline; deal fan |
| Don't Board Me | Page text shows a bouncing-ball loading screen with a percent counter | Squash-and-stretch loader |
| 2026 type trends (Made Good Designs) | Twelve movements: expressive variable serifs, bouba grotesks, retro mono, brutalist display, wide luxury caps, and others; guidance to combine at most two trends and pick the body face first | Font choices for all three themes |
| 2026 web trends (Bellaworks) | Oversized headlines, variable fonts, two font families at most, contrast non-negotiable; kinetic type and custom cursors are risky if overused | Hero layout; ticker kept to one thin strip |
| Mobile game UI review (Pixune) | Oversized icons, strong contrast, colour-coded feedback, constant small responses (Clash Royale, Brawl Stars, Candy Crush) | New feedback section in `MOTION_SPEC.md` |
| Apple Design Awards 2026 | Category criteria only (Delight and Fun, Interaction, Visuals, Inclusivity, Innovation); winners include "Is This Seat Taken?" and "Consume Me" | Principle: delight must never slow the bid flow |
| School of Motion, "Websites with great animation in 2026" | Per-site technique list (scroll typography, cursor interactions, character micro-interactions, 3D responding to the cursor, page transitions) | Variable-weight score; turn glow and table tilt |
